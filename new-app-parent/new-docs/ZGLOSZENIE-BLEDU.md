# Zgłoszenie błędu: format

1. **Tytuł**: proces i objaw w jednym zdaniu
2. **Kroki**: od wejścia na stronę albo wywołania API do objawu
3. **Oczekiwane** i **faktyczne**: konkretne wartości (kwota, data, komunikat)
4. **Dane**: identyfikatory z danych testowych; wyłącznie dane syntetyczne, nigdy dane produkcyjne
5. **Środowisko**: gałąź, commit, przeglądarka
