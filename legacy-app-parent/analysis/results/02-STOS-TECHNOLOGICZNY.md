# Stos technologiczny legacy

Zakres: wyłącznie wskazane pliki konfiguracji, projektów, solucji, opis CZYTAJ.txt, kontrakt WSDL i wcześniejszy raport CLOC. Nie odczytywano treści plików `.vb`, `.aspx`, `.asax` ani `.sql`; wpisy o nich pochodzą z manifestów i pomiaru. Konfiguracja opisuje stan zadeklarowany, nie potwierdza działania ani wdrożenia. **Szacunek** oznacza wniosek o roli, a nie wynik analizy implementacji.

## 7) Krótkie analogie VB.NET WebForms → Java/Spring + React

Poniżej **analogie / propozycje**, nie fakty o istniejącej nowej aplikacji ani mechaniczny plan przepisywania. Dowody wskazują wyłącznie element legacy, do którego odnosi się analogia.

| Element legacy | Analogia w Java/Spring + React | Podstawa w legacy |
|---|---|---|
| `.aspx` + `.aspx.vb` | Komponenty React i obsługa interakcji po stronie klienta + endpointy Spring po stronie serwera. Nie przenosić automatycznie reguł biznesowych do React. | `legacy-app-parent/legacy-app/WypozyczalniaWeb/WypozyczalniaWeb.vbproj:71-112` |
| Core: managery / DAL / modele | Orientacyjnie serwisy Spring / warstwa dostępu do danych (np. JDBC) / modele i DTO. Ostateczny podział dopiero po poznaniu reguł, bez założenia użycia ORM. | `legacy-app-parent/legacy-app/WypozyczalniaCore/WypozyczalniaCore.vbproj:62-82` |
| Web.config, appSettings, connection string | Konfiguracja Spring i środowiska, np. `application.yml`, zmienne środowiskowe i konfiguracja źródła danych. Zachować semantykę kultury i parametrów, nie kopiować ścieżek bez decyzji wdrożeniowych. | `legacy-app-parent/legacy-app/WypozyczalniaWeb/Web.config:11-33` |
| Windows Authentication + InProc Session | Konfiguracja uwierzytelnienia Spring Security/infrastruktury + jawna decyzja o sesji serwera. React nie jest samodzielnym zamiennikiem tych mechanizmów; JWT nie wynika z konfiguracji legacy. | `legacy-app-parent/legacy-app/WypozyczalniaWeb/Web.config:31-33` |
| Web Reference generowany z WSDL | Klient SOAP po stronie Java wygenerowany z kontraktu; interfejs do React może być oddzielnym API Spring, bez zmiany zewnętrznego kontraktu bramki. | `legacy-app-parent/legacy-app/WypozyczalniaWeb/WypozyczalniaWeb.vbproj:114-124`; `legacy-app-parent/legacy-app/WypozyczalniaWeb/Web References/BramkaPlatnosci/BramkaPlatnosci.wsdl:56-91` |
| Konsolowy EksportNocny + Harmonogram Windows | Osobny proces Java uruchamiany przez scheduler albo zadanie Spring; trzeba świadomie zachować godzinę, brak nakładania instancji, limit czasu i uprawnienia do plików. | `legacy-app-parent/legacy-app/Jobs/EksportNocny/EksportNocny.vbproj:9-15`; `legacy-app-parent/legacy-app/Jobs/EksportNocny/zadanie-harmonogramu.xml:9-41` |
